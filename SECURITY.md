# Security policy

This is a portfolio test-automation framework. It runs against public demo
applications (SauceDemo, the OrangeHRM demo) and contains no proprietary code,
production credentials, or customer data — the credentials in `config/config.py`
and `.env.example` are the demos' own published test accounts.

## Reporting a vulnerability

If you find a real security issue in this repository itself (for example, a
dependency with a known CVE, or a way this code could be misused against a
target it wasn't written for), please open a
[GitHub issue](../../issues/new) or email **shahbazhanif87@gmail.com**. There is
no bug bounty; this is a demonstration project, but reports are still welcome
and will be looked at.

Please do not open public issues about vulnerabilities in **SauceDemo** or the
**OrangeHRM demo** themselves — those are third-party applications not
maintained here.

## Supported versions

This repository tracks `main` only; there are no maintained release branches.
